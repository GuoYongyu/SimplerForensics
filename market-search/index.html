市场监管题库与法规检索

在本地检索题库和法规资料，搜索索引完全离线运行。

建立索引中…

支持题干、选项、答案和法规主题的模糊搜索；可在“题库”和“法律法规”之间切换。

扩充本机索引

选择 TXT / Markdown / CSV / JSON 文件，内容保存在当前浏览器。本地 JSON 题目格式为数组，每项可含 question、options、answer；法规或资料项可含 title、content、category、source、url。也可直接导入纯文本。

本地法规库与资料更新

法规快照于 2026-10-16 获取：594 条总局数据库记录，另补充 1 条由后续国家知识产权局规章取代的现行专利申请规定，共保存 595 份 PDF 原文及其全文索引。页面搜索和打开本地 PDF 不需要联网；卡片的“官方来源”链接需要网络。效力状态按官方数据库标注；发现数据库中一条旧规定状态与后续废止文本不一致，已在卡片中标出后续依据。重要使用场景请核对正式文本和适用版本。

PDF 文件位于 data/laws/，法规全文索引为 data/laws-full.json 和页面加载用的 data/laws-full.js。更新官方库可联网运行 python3 market-search/download-corpus.py，单独重建前端索引可运行 python3 market-search/build-law-index.py。题目仍可编辑 data/questions.json 并运行对应的索引生成脚本。
