离线说明与使用边界

本页没有外部脚本、CDN、在线搜索或自动更新请求。数据随页面静态加载；检索、分类筛选和复制都在浏览器本地完成。每条索引附有相应官方手册名称，页面不会自动访问这些站点。

命令按常见工具链整理，语法和选项会随操作系统、软件版本、发行版及集群配置变化。尖括号内容是需要替换的占位符；管道、路径和 shell 语法也可能因 PowerShell、CMD、bash、zsh 而异。集群操作前确认当前 context/namespace；证书排查避免输出或传播私钥与敏感转储。

带有“会改变”标记的命令会修改环境、文件或运行中的服务。执行前先读命令说明并核对目标。
