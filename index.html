YOUR PRIVATE WORKBENCH

常用工具，触手可及。

轻量、离线、即开即用。你的输入和文件只在当前设备上处理。

除工具名称外，还会检索功能页说明和 Linux 命令索引；索引仅在本机建立，不会上传。

按用途浏览，或输入关键词筛选。

01 / FILE ANALYSIS

文件分析

查看文件结构、格式线索、元数据和字节内容。

01 / SIGNATURE

文件格式速查

搜索常见格式的文件头、文件尾签名和已知字段。

↗ 02 / HEX VIEWER

十六进制查看器

按偏移查看原始字节，搜索字节序列并导出选定范围。

↗ 03 / METADATA

文件元数据查看

提取常见文件中的可读元数据，并显示字段来源与解析限制。

↗ 04 / FILE TRIAGE

文件伪装分析

比对扩展名与文件头，查找内部签名、结构异常及有限的隐写线索。

↗ 05 / IMAGE

图片尺寸元数据修复

读取 JPEG、PNG、WebP 尺寸字段；修改后另存派生副本，不覆盖原图。

↗ 06 / EXECUTABLE

EXE 静态分析

分析 PE 结构、哈希和编译语言线索，提取字符串并运行本地规则扫描。

↗ 07 / DIE

DIE 查壳识别

在浏览器内运行 Detect It Easy 的 PE 签名库，识别壳、保护器、编译器与工具链，并汇总取证常用字段。

↗ 08 / X.509

CA 证书分析

粘贴 PEM 或 Base64 证书，在本地解析 X.509 身份、有效期、公钥和 CA 扩展。
